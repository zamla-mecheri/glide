### Project Description

Glide is a simple Auto-Rickshaw Finder system that helps passengers quickly find nearby auto drivers, view estimated fares, and get driver contact details. The system reduces waiting time and improves transparency in local transportation.

---

### The Problem Statement

Passengers often struggle to find nearby auto-rickshaws and face confusion about fares, availability, and driver contact details, especially in unfamiliar areas.

---

### The Solution

Glide provides a lightweight digital platform where users enter their location and distance to destination, and instantly see available autos, estimated fare, and driver details. This makes local travel faster, easier, and more reliable.

#### System Architecture

User → Web Interface → Python Backend → Auto Data → Result Display

The frontend collects user input. The backend processes it using stored driver data and returns available autos with estimated fares.

---

#### Application Workflow

1. User enters current location and distance
2. System searches matching auto drivers
3. Fare is calculated
4. Results with driver name, phone, and fare are shown
